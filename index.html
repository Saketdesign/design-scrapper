Connect Mobbin

MCP selects one iOS app daily. The Chrome bridge downloads all its available screens and animation videos using your existing Mobbin login. Keep Chrome open.

Install the included Mobbin bridge once: open chrome://extensions in Chrome, turn on Developer mode, choose Load unpacked, and select the bridge folder. Then choose Pair Chrome.
